# UX

- Use Angular and ng-bootstrap for all components

# CRUD Flows
- When a Card represents a group of values, there should be a edit button in the top right hand corner of the Card. This should open a modal dialog to edit those values.
- If the Card represents a collection of items (think table), then the item row's last column should have an Edit button. That edit button should open a model dialog to edit the values of the item.
  - There should also be a button in the top right corner of the card of the card with the rows that is an Add button. 
- The Edit modal dialog should have a Save and Cancel button at the bottom of the form, along with an 'X' in the top right hand corner of the modal dialog designed to close and cancel the action.
